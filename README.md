# 自驱型育儿顾问

基于《自驱型成长》（The Self-Driven Child）的科学育儿方法论 Skill——帮父母培养孩子的自律、内驱力和心理韧性（Self-Driven Parenting）

## 项目解决什么问题

孩子自律/自驱力怎么培养？催作业、管屏幕、哄学习越用力越对抗？本技能基于临床神经心理学家威廉·斯蒂克斯鲁德与教育学家奈德·约翰逊的《自驱型成长》，提供从"老板型父母"到"顾问型父母"的落地方法、话术与场景方案。

## 核心框架

```
安全感（安全基地）→ 自主感(控制感) ◄► 价值感(胜任感) → 自驱型大脑
```

一句话：父母最重要的不是帮孩子取得成功，而是让孩子拥有努力活出自己人生的意愿。

## 主要功能

| 能力 | 说明 |
|------|------|
| 父母角色转换 | 从"命令、督促、批评"转向"提问、建议、共情"，"这事听你的" |
| 沟通黄金法则 | 提问代替命令、成长型表扬、每日三赞、非焦虑临在 |
| 四大科学要点 | 慢性压力损害大脑 / 控制感是压力解药 / 自驱力=控制感+胜任感+自主感 |
| 典型场景方案 | 家庭作业之战、孩子考砸了等常见冲突的应对流程（references/scenarios） |
| 输出规范 | 每次聚焦 1-2 个核心原则、必含可直接使用的话术、给出 1 个当晚行动、温暖而非说教 |
| 安全边界 | 明确不适用场景（虐待/家暴、心理健康危机、确诊疾病、需医学干预的问题） |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖

## 使用方法

触发场景：孩子自律/自驱力/内驱力培养、父母角色定位与亲子沟通、学习动力与作业问题、焦虑与情绪管理、电子产品与屏幕时间、表扬与激励方式、睡眠与大脑健康、教育原则与边界设定、顾问型父母/非焦虑临在实践。

## 输入输出示例

**输入：** 儿子四年级，写作业拖拉，催就发脾气，怎么办
**输出：** 核心原则定位（自主感缺失）+ 停止催促的边界设定方案 + 可直接使用的话术 + 当晚行动

**输入：** 女儿数学考砸了，把自己关在房间里
**输出：** 先处理情绪再处理问题的沟通流程 + 成长型心态话术 + 当晚行动
