# 实用工具与话术模板

## 一、沟通话术矩阵

### 用提问代替命令

| 场景 | 不要这样说 | 尝试这样说 |
|------|----------|----------|
| 孩子遇到问题时 | "你又闯祸了？" | "发生了什么事？" |
| 孩子哭闹时 | "别哭了" | "你的感受是什么？" |
| 孩子寻求帮助时 | "你该这样做" | "你觉得有什么办法？" |
| 孩子成功后 | "你太棒了" | "你是怎么做到的？" |

### 顾问式父母的开场白

- "我有些想法，你想听吗？"
- "我知道这很难，你想聊聊吗？"
- "这是你的事，我尊重你的决定。如果你需要，我随时在。"
- "没人比你自己更了解你，你完全有能力对自己的决定负责。"

## 二、成长型表扬公式

**公式：描述行为 + 点出品质 + 表达感受**

❌ "你真聪明！"
✅ "这道题你试了三种方法才做出来，这就是坚持！爸爸为你骄傲。"

❌ "画得真好！"
✅ "你用了三种颜色搭配，还画了光影，能看出你观察得很仔细。"

❌ "考了100分，真棒！"
✅ "你为了这次考试准备了整整两周，每天复习不同的章节，这就是有计划。"

## 三、每日三赞清单

每天至少发现孩子三个闪光点并具体表扬。记录示例：

1. 今天______（行为），体现了______（品质）。
2. 今天______（行为），体现了______（品质）。
3. 今天______（行为），体现了______（品质）。

## 四、非焦虑临在自检清单

在跟孩子互动前，问自己：

- [ ] 我现在平静吗？
- [ ] 我是带着情绪在说话，还是在解决问题？
- [ ] 我此刻的焦虑是来自孩子的问题，还是我自己的压力？
- [ ] 如果我现在生气/焦虑，孩子会学到什么？

## 五、彻底停工期安排

**每日最低要求：**
- 学龄前：无结构化玩耍时间 ≥ 1小时
- 小学生：自由活动时间 ≥ 45分钟
- 青少年：自主时间 ≥ 30分钟

**停工期可以做什么：**
- 发呆、做白日梦
- 户外活动（非组织化运动）
- 自由绘画/手工
- 听音乐
- 家庭无电子产品时间

**不可以做什么：**
- 安排学习任务
- 催促或打断
- 评价"你怎么不去做XX"

## 六、电子产品管理协商框架

**第一步：共同制定规则**
- "我们一起来想想，每天用什么时间玩手机/平板最合适？"
- "你觉得每天玩多久是合理的？"

**第二步：设置提醒机制**
- 用计时器而非家长催促
- 提前5分钟提醒："还有5分钟到约定时间了"

**第三步：无电子产品时间**
- 餐桌上
- 睡前1小时
- 家庭活动时间

**第四步：处理违规**
- 用"我们的约定是什么？"而非"你怎么又这样"
- 让孩子自己说出后果并执行
