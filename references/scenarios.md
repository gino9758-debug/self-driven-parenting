# 常见场景应对指南

## 场景一：家庭作业之战

**核心原则：** 作业是孩子的责任，不是父母的战场。

**策略：**
1. 把作业决策权还给孩子："你想先做哪一科？"
2. 做顾问而非监工：孩子卡壳时问"你卡在哪一步了？"而非直接给答案
3. 设定边界而非盯梢："8点前我会帮你检查一遍，之后是你的时间"
4. 允许自然后果：不完成作业的后果由孩子承担（与老师沟通好）

**话术：**
- "我相信你能安排好。如果需要帮助，我就在隔壁。"
- "这题确实不容易，你先说说你理解的题目要求是什么？"

## 场景二：孩子考砸了

**核心原则：** 考试是信息，不是判决书。

**策略：**
1. 先处理情绪，再处理问题
2. 问"你从这次考试中学到了什么？"而非"怎么考这么差"
3. 和孩子一起分析：哪些掌握了，哪些还需要努力
4. 强调成长型心态："这次没考好说明你还在学习的路上"

**话术：**
- "我看到你有点沮丧，想聊聊吗？"
- "你觉得这次考试里，哪部分是你最满意的？"
- "如果重来一次，你会在哪方面花更多时间？"

## 场景三：孩子沉迷电子产品

**核心原则：** 协商代替禁令，自控代替他控。

**策略：**
1. 和孩子共同制定使用规则
2. 用计时器而非家长催促来管理时间
3. 提供替代活动：运动、户外、亲子游戏
4. 家庭带头示范：家长自己也遵守无电子产品时间
5. 关注背后需求：孩子是在逃避压力？缺乏社交？寻求刺激？

**话术：**
- "我注意到你最近花很多时间在游戏上，是有什么特别吸引你的吗？"
- "我们一起想想，每天用什么时间玩最合适？"
- "约定时间到了，你自己关还是我来提醒？"

## 场景四：孩子缺乏学习动力

**核心原则：** 动力来自内在，而非外在压力。

**策略：**
1. 帮助孩子找到兴趣连接点："这门课里有什么是你觉得有意思的？"
2. 设定由孩子主导的SMART目标
3. 用"你是怎么做到的？"强化成功经验
4. 减少外部奖励，增加内在满足
5. 允许孩子体验选择的后果

**话术：**
- "如果你学好了这门课，你觉得会有什么不一样？"
- "你上次做成那件事的时候，是什么感觉？"
- "这个目标是你自己定的，还是有谁在推你？"

## 场景五：孩子与父母对抗/叛逆

**核心原则：** 对抗是自主权需求的信号，不是敌意。

**策略：**
1. 不升级冲突：深呼吸，暂停对话
2. 承认孩子的感受："我知道你很不高兴"
3. 区分"必须坚持的底线"和"可以放手的小事"
4. 在安全范围内允许孩子试错
5. 修复关系优先于纠正行为

**话术：**
- "我听到你说不想做，能告诉我为什么吗？"
- "这件事对你很重要，我理解。同时我也有我的担心，我们能不能一起想个办法？"
- "现在我们都挺激动的，等平静下来再聊好吗？"

## 场景六：孩子过度焦虑/压力大

**核心原则：** 压力是信号，不是敌人；控制感是最好的解药。

**策略：**
1. 先检查基础：睡眠是否充足？是否有停工期？
2. 帮助孩子识别压力源："你觉得最让你紧张的是什么？"
3. 教孩子备选计划思维："如果最坏的情况发生了，你还有什么选择？"
4. 练习积极自我对话："人可以失误，这很正常"
5. 必要时寻求专业帮助

**话术：**
- "你最近看起来压力很大，想跟我说说吗？"
- "如果这件事没按你想的发展，最坏会怎样？你能承受吗？"
- "你已经做了你能做的，剩下的部分不在你控制范围内。"

## 场景七：多孩家庭的公平感问题

**核心原则：** 公平不等于一样，每个孩子需要不同的支持。

**策略：**
1. 给每个孩子单独的"特别时间"
2. 避免比较："你看你哥哥……"
3. 根据年龄调整自主权范围
4. 家庭会议让孩子参与规则制定

**话术：**
- "你们两个不一样，我需要用不同的方式支持你们。"
- "这是你和我的特别时间，只属于我们。"
